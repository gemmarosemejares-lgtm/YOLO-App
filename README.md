## Final Project – Mobile App Development

YOLO-App is a modern mobile shopping application developed using Android Studio with Kotlin, Flask REST API, and MySQL database integration.
The application is designed to provide users with a fast, convenient, and enjoyable mobile shopping experience. Users can create accounts, securely log in, browse different product categories, add items to their cart, and manage their profile within the application.
The system uses a Flask REST API as the backend service to handle communication between the Android application and the MySQL database. This allows real-time data processing, user authentication, and efficient storage of user information.
The project also focuses on creating a clean and responsive user interface inspired by modern e-commerce platforms. Different layouts, product displays, profile management features, and navigation components were implemented to improve user experience and accessibility.

# How to Run the Project
Android App
1. Open the project in Android Studio
2. Connect emulator or Android device
3. Run the application
Flask API
1. Open terminal
2. Go to flask_api folder
3. Run:
python app.py
4. Flask server will run on:
http://127.0.0.1:5000
